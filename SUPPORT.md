# Getting help

- **A bug or a feature request for an open-source project:** open an issue in that
  project's repository. Search the existing issues first, and include the version, your
  environment and the exact error.
- **A security problem:** follow the [security policy](SECURITY.md). Do not open a public
  issue.
- **AllsWeb services** (managed IT, hosting, domains, SixPanel, custom work): use
  <https://www.allsweb.com/support>.

Issues are answered by the maintainers as time allows. Paid support with a response time
is available through AllsWeb.
