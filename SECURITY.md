# Security policy

This policy applies to every public repository of the AllsWeb organisation that does not
have its own `SECURITY.md`.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

1. Preferred: open the affected repository, go to **Security → Advisories → Report a
   vulnerability** and send a private report.
2. If that option is not available for the repository, write to **hi@allsweb.com** with
   the subject "Security report" and the repository name.

Include the version or commit, the steps to reproduce and the impact you expect. Remove
passwords, tokens, keys and personal data from anything you send.

You will get a first answer within 5 working days. Once a fix is released we publish the
advisory and credit you, unless you prefer not to be named.

## Supported versions

Fixes are made on the latest release of each project, unless that project's own security
policy says otherwise.
